# IMDb Movie Review Data Cleaning & Analysis

## About the Project

This project analyzes the IMDb movie review dataset using Python,
Pandas, NumPy and Matplotlib.

## Dataset

Source: Hugging Face
Dataset: stanfordnlp/imdb

Original training records: 25,000
Final records after removing duplicates: 24,904

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Google Colab
- Hugging Face

## Analysis Performed

- Missing-value analysis
- Duplicate detection and removal
- Sentiment distribution
- Review-length analysis
- Mean, median, minimum and maximum calculations
- Comparison of positive and negative review lengths

## Results

Positive reviews: 12,472
Negative reviews: 12,432

The dataset contains almost equal numbers of positive and negative
reviews.
